# Hotel Management System (C++)

## Project Description

A console-based Hotel Management System developed using Object-Oriented
Programming (OOP) in C++. The application supports room booking,
customer search, checkout, room status management, and file handling
using `fstream`.

## Objective

-   Apply OOP concepts
-   Practice file I/O
-   Prevent double booking
-   Manage customer and room records

## Features

-   Book Room
-   Checkout Room
-   Search Customer
-   View All Rooms
-   Double-booking prevention
-   Menu-driven program

## Sample Execution

1.  Main Menu
2.  Book Room (Success)
3.  Double Booking Attempt
4.  Search Customer
5.  Checkout Room
6.  View All Rooms & Exit

## Requirements

-   C++ compiler

## How to Run

``` bash
g++ hotel_management.cpp -o hotel
./hotel
```
